How art lives in Australian public collections

Public galleries form a nationwide network. The following maps examine this broader context before turning to artworks in Brisbane’s public spaces.

A national network of public galleries

Each dot marks a gallery in the available dataset. Galleries are concentrated along Australia’s populated east and south-east coasts, setting the national context for the city collections explored below.

Gallery coverage varies by state

Circle size shows the number of galleries with usable locations in each state. The circles sit at state and territory capitals so the counts can be compared without overlapping individual gallery points.

Melbourne’s collection is led by sculpture

Each point represents a public artwork. The classification colours show that sculptures make up most of the mappable collection, while memorials form a smaller, distinct group.
